## 三、项目约束（必须遵守）

> 以下为项目硬约定，AI 必须遵守（摘自项目 CLAUDE.md，可按需增删）。

- 技术栈：后端 FastAPI + SQLite，前端 Vue 3 + Element Plus + Vite。
- **模块化设计**：新功能按模块组织，每模块职责单一、可独立测试。
- **权限**：新增/修改/删除 API 后，必须在 `lesson/config/api_permissions.yaml` 同步权限配置（路径、方法、角色、资源/动作范围等）。DB 为权限权威，启动自动落库。
- **数据库**：SQLite。schema 变更走**幂等自动迁移**（CREATE IF NOT EXISTS / ALTER 容错），**严禁覆盖服务器数据库文件**。
- **性能**：同步 SQLite / 文件 / Excel 等阻塞操作，不要放在 `async def` 端点里卡事件循环；重活端点用同步 `def`（进 anyio 线程池）。
- **代码风格**：Python 遵循 PEP 8，前端遵循 ESLint。改动做外科手术式修改，不顺手重构无关代码。
- **验证**：改完必须跑测试/build，不允许只改不验；不许为跑通而注释掉报错。
- **部署**：用 deploy-pack 增量打包；**不要自动 git push**（等开发者指令）。
