# 系统功能清单（通俗版）

> **这份清单是给老师、年级组长、校领导看的**：告诉你系统现在能做什么，不用懂技术。
> 想找某个功能、或想确认"系统能不能做 XX"，先在这里查。
> 每次上线新功能都会更新这份清单。最后更新：2026-11-23。

---

## 一、看数据：数据驾驶舱

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 总览驾驶舱 | 一屏看全校关键数据：学生、德育、教学总体情况 | 校领导 |
| 班级驾驶舱 | 看某个班的各类数据与趋势 | 班主任 |
| 年级驾驶舱 | 看整个年级的对比和趋势 | 年级组长 |
| 德育驾驶舱 | 看德育记录、处分、预警的整体情况 | 德育负责人、校领导 |
| 教学驾驶舱 | 看教学相关数据 | 教务、校领导 |
| 监考驾驶舱 | 看监考安排的整体情况 | 教务 |
| 系统驾驶舱 | 看系统运行状态 | 系统管理员 |
| 教师工作台 | 老师一进来就能看到自己的待办、相关数据 | 全体老师 |

## 二、管学生：德育管理

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 日常表现记录 | 记录学生日常好坏表现（加分/扣分），支持批量录入 | 班主任、任课老师 |
| 点滴记录 | 随手记录学生的闪光瞬间或小问题 | 班主任、任课老师 |
| 校级事件 | 登记全校性的表彰或违纪事件 | 学发 |
| 德育任务 | 布置德育任务并记录完成情况 | 班主任、学发 |
| 处分管理 | 登记、管理、撤销学生处分 | 学发 |
| 德育评价 | 自动算学生德育分，出评价结果 | 班主任、学发 |
| 学期评价 | 学期末的综合德育评定 | 班主任、学发 |
| 集体评价 | 班级等集体的德育评价 | 学发 |
| 学生画像 | 生成单个学生的综合表现画像 | 班主任、心理老师 |
| 一生一册 | 学生在校期间的全程成长档案 | 班主任、学发 |
| 生日提醒 | 学生生日提醒，方便送祝福 | 班主任 |
| AI 诊疗 | 针对学生问题，AI 辅助分析原因、给教育建议 | 班主任、心理老师 |
| 导师制 | 给学生分配导师，记录谈心谈话 | 导师、班主任 |
| 预警名单 | 自动筛出需要重点关注的学生 | 班主任、学发 |
| 升级规则 | 设置问题升级的自动规则（如多次违纪自动上报） | 学发 |

## 三、管教学：课程与班级事务

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 课程表 | 查看班级/教师课表 | 全体老师 |
| 实时课程 | 看当前正在上什么课 | 全体老师 |
| 总课表 | 查看全校总课表和各周课表文件 | 全体老师 |
| 更新课表 | 上传/更新课表文件 | 教务 |
| 班级作业 | 发布、查看班级作业 | 任课老师、班主任 |
| 班级信息 | 维护班级基本信息 | 班主任 |
| 班级学生 | 查看、管理本班学生名单 | 班主任 |
| 班级公告 | 发布班级通知公告 | 班主任 |
| 延时申请 | 学生延时服务申请与审批 | 班主任、家长 |
| 请假记录 | 学生请假登记与记录 | 班主任 |
| 随机点名 | 课堂随机点名，活跃气氛 | 任课老师 |
| 大声 PK | 课堂朗读音量比拼小游戏 | 任课老师 |

## 四、管考试：监考安排

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 监考安排 | 排监考表，支持手动排和 Excel 导入，含主监/副监 | 教务 |
| 变更通知 | 安排有变动时，一键微信通知相关老师（新增/取消/换监） | 教务 |
| 自动提醒 | 开考前自动给监考老师发微信提醒（考前 30 分钟起，每 5 分钟一次，共 2 次） | 系统自动 |
| 工作量报表 | 导出教师监考工作量（主监/副监场次分开，可按权重折算） | 教务 |
| 权重设置 | 设置主监/副监的工作量折算权重 | 教务、管理员 |

## 五、帮老师办公：个人事务

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 每日早报 | 每天的新闻要闻、微语和音频，顶部显示当前周次（单双周、延时年级） | 全体老师 |
| 我的待办 | 个人待办事项，到点微信提醒 | 全体老师 |
| 协作群组 | 待办按分组管理，可与同事协作 | 全体老师 |
| 教师消息 | 接收系统/学校消息 | 全体老师 |
| 文件上传/我的文件 | 上传、管理自己的文件 | 全体老师 |
| 文件管理/已查阅 | 收齐并查阅老师提交的文件 | 教务 |
| 需求中心 | 看系统已有功能（功能大厅）、提交功能建议、跟踪处理进度 | 全体老师 |

## 六、管系统：后台管理

| 功能 | 能做什么 | 适合谁 |
|------|----------|--------|
| 教师管理 | 维护教师账号与信息 | 管理员 |

| 系统监控 | 查看系统运行与访问情况 | 管理员 |
| 数据库管理 | 数据库查看、备份与恢复 | 管理员 |

## 没找到你要的功能？

如果这里有你想用但找不到入口的功能，或者你希望系统**新增**某个能力，请按开发流程提需求：
- 小改动（改个文字、修个问题）：直接告诉技术负责人即可。
- 新功能：填写《需求卡片》（见 `docs/process/templates/01-需求卡片.md`），说明你要解决什么问题、期望什么效果。

> **给维护者**：本清单面向使用者，请保持通俗。每次功能上线必须同步更新此表，并更新顶部日期。
