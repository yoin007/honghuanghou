# 功能设计说明：需求中心页面（给使用者审核）

## 基本信息

- **需求编号**：REQ-2026-003
- **版本**：v1（2026-11-23）

## 1. 这个功能帮你解决什么？

不用再问"系统能不能做 XX"——打开「需求中心」就能看到全部已有功能；想提建议直接在系统里填表，进度随时可查。

## 2. 做好后，你在系统里会看到什么变化？

左侧菜单「教师」组新增一项 **【需求中心】**，页面有三个区块：

**① 功能大厅**：按六大类展示系统已有功能（看数据 / 管学生 / 管教学 / 管考试 / 帮老师办公 / 管系统），每条写清"能做什么、适合谁"。看完想提需求，点"我要提需求"。

**② 我要提需求**：一个简单表单，填 4 项——
- 一句话概括（必填）
- 遇到什么问题（必填）
- 谁在什么场景下遇到（选填）
- 希望达到什么效果（必填）

提交后立刻显示编号（如 REQ-2026-005），提示"已收到，可在『我的需求』查看进度"。**不用懂技术，大白话写就行。**

**③ 我的需求**：一张列表显示你提交过的需求，每条有状态标签：
> 待澄清 → 设计中 → 待审核 → 开发中 → 待验收 → 已上线（或 已搁置）

点开任意一条能看到**进展时间线**（何时收到、何时确认、何时开发……），有新进展你会在这里看到。

## 3. 教务/管理员多看到什么？

- 列表显示**所有人**的需求；
- 点开需求可以把状态往前推进（附一句说明），比如"已确认，进入设计"；
- 全部动作自动留痕，谁改的一目了然。

## 4. 几个你会关心的问题

- **别人能看到我提的需求吗？** 不能。普通老师只能看到自己提交的；只有教务/管理员能看全部。
- **我提的需求会被处理吗？** 每条都会进入开发流程台账，状态会持续更新；不会悄悄消失。
- **填错了能改吗？** 提交后内容不能改，但可以追加"补充说明"；写错了教务会联系你确认。
- **会通知我进展吗？** 目前需要自己进页面看（后续版本会加微信提醒）。

## 5. 这次不做的部分

- 不做需求间的讨论区/投票（后续看使用情况再加）；
- 不做提交后的微信自动提醒（v1 需主动查看）。
