# 需求卡片：监考工作量主副监权重折算

## 基本信息

- **需求编号**：REQ-2026-001
- **提出人**：Tech_T（转达教务/学发的统计口径要求）
- **日期**：2026-11-17
- **通道**：完整流程

## 1. 我想解决什么问题？

工作量报表目前主监、副监完全同权：都算 1 场、都拿整场时长。但学校考核口径里副监的工作量和主监不一样，报表数字和实际考核对不上。

## 2. 谁在什么情况下会遇到这个问题？

教务在每次考试后导出监考工作量报表、核算教师工作量时。涉及所有参与监考的老师。

## 3. 我希望达到什么效果？

- 主监、副监的折算权重可以在系统里人工配置（教务/管理员），不用改代码。
- 报表按权重折算场次和时长；同时**主监、副监的原始场次分开列出**，权重设为 0 也照常计数（只是折算归零）。
- 时间数据有错漏的场次不能让"场次"和"时长"对不上。

## 4. 怎样算"做好了"？（验收标准）

- [ ] 教务/管理员能在系统里直接设置主监、副监权重，无需开发人员介入
- [ ] 设置副监权重 0.5 后，报表里副监一场计 0.5 场、时长按 0.5 折算
- [ ] 报表同时显示主监场次、副监场次（原始计数），权重为 0 时场次仍显示真实数字
- [ ] 时间格式有错的场次从场次和时长中同时排除，两列永远对得上
- [ ] 导出报表时系统其他页面不卡顿

## 5. 特别要注意的

- 权重配置只能给教务和管理员，普通老师不能改。
- 服务器数据库不能动，新配置必须自动建表。
