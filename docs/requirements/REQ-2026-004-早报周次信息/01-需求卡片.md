# 需求卡片：每日早报展示当前周次信息

## 基本信息

- **需求编号**：REQ-2026-004
- **提出人**：Tech_T
- **通道**：轻量（单卡片）
- **状态**：待验收
- **日期**：2026-11-23

## 需求描述

在「每日早报」页面顶部展示当前周次信息，让老师打开早报就能确认本周的单双周和延时年级，不用再去别处查。

**显示内容**（跟随页面所选日期联动）：

1. 第几周（周次编号）
2. 单双周（奇数周=单周，偶数周=双周）
3. 延时信息（单周=高二延时，双周=高一延时，口径与周信息列表的延时标签一致）

## 设计要点

- 新增公开接口 `GET /api/week-info?date=YYYY-MM-DD`（挂在 daily_news_api，与早报页面同为免登录；周次 = 日历周 + week_change 偏移，week_change 从 lesson.yaml 读取）
- 页面头部日期行下方加三个标签，视觉层级为「周次弱化、单双周实色、延时最醒目」：`第 N 周`（玻璃质感）/ `单周|双周`（单周暖橙、双周晴空蓝实色渐变）/ `高一延时|高二延时`（反白大胶囊加粗，带时钟图标）
- 接口失败时静默隐藏，不影响早报主流程；历史日期按同一口径计算

## 验收清单

- [ ] 打开每日早报，头部显示 第N周 / 单双周 / 延时年级 三个标签
- [ ] 切换日期到上周/下周，周次和延时标签跟着变
- [ ] 延时口径与已有的周信息列表一致（同一周显示同一延时年级）
